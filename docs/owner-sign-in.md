# چوونەژوورەوەی خاوەن فرۆشگا

- چوونەژوورەوەی سەرەکی بە ژمارەی مۆبایلی عێراقی و پاسوۆردە. پێش چالاککردنی هەژمار، بەڕێوەبەر خاوەندارێتی ژمارەکە پشتڕاست دەکاتەوە. هەژماری هەبوو هەمان ناسنامەی ناوخۆیی دەپارێزێت.
- لە دەستپێکدا SMS و Telegram Gateway بەکار نایەن. گەڕاندنەوەی هەژمار بە پشتڕاستکردنەوەی بەڕێوەبەرە و پاسوۆرد لە چاتی پشتگیری وەرناگیرێت.
- بۆتی تێلەگرام هەڵبژاردەیەکی زیادەیە. خاوەن فرۆشگا لە دانیشتنێکی پشتڕاستکراودا لینکێکی یەکجارە دەکاتەوە، Start دادەگرێت و بەستنەوە لە داشبۆرد پشتڕاست دەکاتەوە. ئەمە دەستڕاگەیشتن بە تێلەگرام پشتڕاست دەکاتەوە.
- دوای چالاککردنی تێلەگرام بۆ هەژمارێک، دەستڕاگەیشتن بە داتای تایبەتی داشبۆرد و نووسین لە داتابەیس هەتا پشتڕاستکردنەوەی کۆدی یەکجارە بۆ هەمان دانیشتن ڕادەگیرێت. یاساکان لە سێرڤەر و داتابەیس جێبەجێ دەکرێن.
- بەستنەوە، کۆد و دانیشتنی پشتڕاستکراو لە سێرڤەر بەڕێوەدەبرێن. کۆدەکان کاتی سنووردار و سنووری ژمارەی هەوڵیان هەیە. توکنی بۆت تەنها لە نهێنییەکانی سێرڤەر دەهێڵرێتەوە.
- قۆناغی یەکەم بە تاقیکردنەوەی چوونەژوورەوە بە ژمارە و پاسوۆرد بەردەوام دەبێت. هەڵبژاردەی تێلەگرام تەنها دوای تاقیکردنەوەی تەواوی بەستنەوە، کۆد و مۆڵەتی داتابەیس چالاک دەکرێت.
